# Voluntary evaluation feedback

Submit voluntary feedback through [Open-Core evaluation feedback](https://github.com/elevate-labs-dev/android-subscription-notes/issues/new?template=sdk-evaluation-feedback.md). GitHub sign-in is required; downloading the package does not require feedback or a GitHub account.

The SDK template, issue submission and maintainer read/close workflow were verified on 13 October 2026. [Verification issue](https://github.com/elevate-labs-dev/android-subscription-notes/issues/1) is a maintainer test, not external feedback or demand evidence. Anonymous intake can be reconsidered if observed sign-in friction materially prevents evaluation feedback.

Never post credentials, account emails, purchase tokens, private source or unredacted logs. Public issues are visible to everyone.

## Optional product feedback

- Where would you use this? What do you currently use instead?
- What happened during your last comparable integration?
- Which missing capability would make the SDK useful?
- Which Pro capability would merit payment? Budget and currency, if known:
- Would annual one-product-app rights, including staging/QA and team access, fit your use?

Submitting feedback is optional. Downloads, successful integrations, use cases and hypothetical price answers are recorded separately. No payment commitment is implied.
